# BorderFlow 課程錄影流程（約 8–10 分鐘）

1. **0:00–0:45** 介紹課題、雙介面和官方資料與演示資料的分界。
2. **0:45–2:00** 開啟旅客端，切換居民／訪客與方向，點選羅湖與深圳灣比較等候及接駁，展示歷史圖。
3. **2:00–3:20** 開啟營運端，登入，查找 DEMO-0002，查看覆核備註，按口岸及方向篩選過關流水。
4. **3:20–5:00** 運行 60 分鐘模擬，滑動至隊列開始形成的分鐘，增加通道後重跑並回看兩個情景。
5. **5:00–6:40** 建立演示預約、查看稽核、取消後展示配額恢復。展示 200 請求測試結果。
6. **6:40–8:00** 打開資料庫實驗室，比較全表與索引查詢。展示對帳輸出與口岸別名。
7. **8:00–9:00** 說明資料來源、假設和已驗證範圍，從營運端登出。
